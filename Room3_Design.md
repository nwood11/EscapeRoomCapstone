# Room 3 - Circular Control Room Design

## Layout
- Circular room design with central hub
- Radius: ~800 units
- Control panels arranged around perimeter

## Key Elements
- Central command console
- 8 workstations positioned radially (every 45 degrees)
- Curved walls with monitors/screens
- Multiple entry/exit points
- Overhead lighting system
